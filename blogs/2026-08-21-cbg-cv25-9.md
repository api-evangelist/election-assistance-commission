CBG-CV25-9 jle Friday, August 21, 2026 Manufacturer Clear Ballot Group, Inc. Testing Lab Pro V&V Impacted Device/System ClearVote 2.5 Date Submitted by Manufacturer 08/20/2026 Date Approved by EAC 08/21/2026 Short Description of Changes This minor change enables the ClearCast Go software to utilize the status output of the existing Ultrasonic Sensor (USS) so the feature can be used during the November 2026 General Election. The USS hardware component was already included in the certified ClearVote 2.5 voting system but was disabled during testing.
